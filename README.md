# Java-Basics

## What is this project?

This is a full Java learning resource designed to help new students to CS understand core Java concepts through practical examples. The project covers everything from imperative programming fundamentals to advanced concepts like concurrency and network communication. Each topic includes well-documented code examples with comments explaining key concepts. These are my lecture notes from the course "Programmieren 1" of the *Technische Universität Berlin* and just so you know, I don't take any responsibility if you screw up your exam in uni.

## Project Structure

The project is organized into four main categories within the `src` folder:

**1. ImperativeProgramming** - Foundational programming concepts including arrays, loops, methods, recursion, and basic object-oriented programming introduction.

**2. ObjectOrientedProgramming** - Core OOP principles covering classes, objects, inheritance, interfaces, abstract classes, enums, inner classes, anonymous classes, wrapper classes, and the String class. Includes both basic concepts (constructors, getters/setters, JVM behavior) and advanced topics (coding to interfaces, access modifiers).

**3. AlgorithmsAndDatastructures** - Common data structures and algorithms including arrays, linked lists, generics, abstract data types (lists, maps, sets, queues, stacks, trees, graphs), sorting algorithms, and search algorithms.

**4. AdvancedConcepts** - Advanced Java topics including:
- Concurrency (threads, runnables, callables, locking, deadlocks, interruption, wait/notify)
- Exception handling and failure management
- I/O streams and autocloseable resources
- Network communication (sockets, client-server architecture)
- Introduction to Kotlin

## How to Use This Project

### How to Get Started

1. **Clone the Repository**: Clone this repository to your local folder using the following command:
   ```
   git clone <https://github.com/MrMillennium01/Java-Basics.git>
   ```

2. **Open the Project**: Open the project in your Java IDE (e.g., IntelliJ IDEA - they are free for everyone and students even get their premium features).

3. Theat's it, it's really not that deep.

### Reading the Code

1. **Browse the categories** - Navigate to the `src` folder and explore the different packages based on what you want to learn.

2. **Read the JavaDocs** - Almost each file containes Javadocs, which can be viewd as description and introduction to a topic.

3. **Study the inline comments** - The code includes inline comments that explain further details.

### Running the Code

1. **Find files with main methods** - Most example files contain a `main` method that you can run directly. Look for files named `Main.java` or classes with a `public static void main(String[] args)` method.

2. **Observe the output** - Pay attention to what gets printed to the console (System.out.println( some stuff )) to see, how the code affects constants etc.

### Experimenting and Learning

1. **Modify parameters** - Change values in the main methods to see how different inputs affect the output. Go wild and experiment as your liking. Don't be afraid of running into errors, they are part of learning and you can always go back.

2. **Add your own examples** - Extend the existing code with your own test cases to see, if you can apply the knowledge to your projects.

3. **Break things intentionally** - Try removing certain pieces of code or using incorrect values to see what errors occur. This helps you understand error messages and debugging.

4. **Compare implementations** - Many topics show different ways to accomplish the same task. Compare and contrast these approaches.
